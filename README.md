## 🚀 About

Multiverse OS is my personal interactive portfolio designed to feel less like a traditional developer website and more like an explorable digital world.

It showcases my projects, skills, experience, achievements, and developer profile through an interactive UI.

## ✨ Features

- 🌌 Interactive Multiverse OS interface
- 🎨 Spider-Verse-inspired visual design
- ⚡ Smooth animations and interactive effects
- 🧩 Dynamic project showcase
- 🛠️ Skills and technology sections
- 💼 Experience and achievements
- 🔗 GitHub, LinkedIn and X integration
